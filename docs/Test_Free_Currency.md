# 当前测试版：货币无消耗

V0.10框架测试仍启用此规则。当前验收以 `evidence/framework-tests/results.json` 的16组回归和免扣专项39项检查为准；下文旧模块测试数字属于历史记录。新玩法入口和专用材料边界见《V0.10-试玩指南.md》。

2026-10-08。退出旧游戏后，运行桌面 `洪荒/游戏/Honghuang.exe` 或 `启动洪荒.lnk`。

该版本通过项目设置 `testing/free_currency=true` 开启测试支付规则；普通档、展示档均生效。原始余额继续显示，支付不扣余额，余额不足或为零也不阻止支付。奖励正常获得并保存。窗口标题、主页等级行、各页面标题及招募按钮说明带有测试提示。

覆盖：灵石、修为、灵材、灵药、召唤符、道缘、仙盟贡献、两种庆典代币，以及守府玩法铜钱和离线拍卖演练币。对应招募、兑换、角色培养、法宝修复、装备强化的灵石费用、仙府建造/升级/加速/生产、修行培养、材料商店、活动入场/扫荡、仙盟商店/捐献都使用免扣支付。

专用材料和实物保持原规则：宝胚、淬灵精华、鱼饵、升星碎片、合成时选择的装备、丹药等仍需持有并会消耗。每日次数、购买额度、仓库容量、生产时间、等级上限和玩法解锁也保留。招募概率、保底、结果转换不变。累计消耗任务按照实际消耗记录，免扣货币不会虚增消耗进度。

免费培养不新增已付费台账；生产订单同时保留原配方报价和实付金额。免费订单取消退零，旧付费订单按原投入退款；混合付费/免费升级的重置只退真实投入。旧档中没有实付字段的生产订单沿用原退款规则。无需修改存档结构版本或给钱包充值，余额和存档校验没有被放宽。

测试结果和新增角色、装备仍属于正常游戏进度，会保存在当前档案。此修改不会复制、删除或覆盖 AppData 玩家存档。若需要回到收费规则，在源码 `project.godot` 关闭此项目设置并重新导出；历史免费订单仍按零实付退款。测试不能用于判断正常资源供需或消费曲线。

验证：Godot 4.6.3 Windows；免扣专项 260 项检查通过，覆盖真实命令、零钱包 UI 操作、单抽/十连/保底、仙盟与庆典、独立活动、退款、混合旧投入、写入失败、刷新恢复及同一事务防重放。另运行原收费模式的经济、装备、仙府、修行、仙盟、活动和存储回归，以及原收费模式影片流程。实际 Windows EXE/PCK 的导出验证报告位于 `召唤-release-runtime.json`；该报告验证导出设置已开启免扣、零召唤符十连、影片播放、立绘顺序和跳过，未冒充其他平台真机验收。

复测：在隔离的 APPDATA 下执行 `godot --headless --path . --script res://tests/test_free_currency.gd`；原收费回归使用 `python tests/run_bounded.py <test 文件...>`，该运行器自动传入 `--balanced-economy`，不影响导出的默认免扣行为。测试用存档隔离，生产存档不参与测试。
